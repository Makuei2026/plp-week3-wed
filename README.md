# Personal Budget Tracker - Visual Design & Styling

## Project Overview
This project is an enhanced version of the **Personal Budget Tracker** application. In this iteration (Week 3), the focus was exclusively on visual design, typography, spacing, and component styling using custom CSS, without altering the foundational HTML structure.

---

## What Was Built & Features Implemented

### 1. Intentional Color Palette (25%)
- **Primary Theme:** Deep Slate Blue (`#2b6cb0`) used for primary branding, headings, and primary buttons.
- **Backgrounds:** Off-white/light grey background (`#f7fafc`) for reduced eye strain and pure white cards (`#ffffff`) for contrast.
- **Contextual Colors:** Distinct status colors for income (Forest Green) and expenses (Crimson Red) used across table badges and transaction amounts.

### 2. Custom Typography (20%)
- **Heading Font:** Linked and applied **'Inter'** (sans-serif) from Google Fonts for bold, modern section headers and table column titles.
- **Body Font:** Applied **'Poppins'** (sans-serif) for general content, form labels, inputs, and table data cells to ensure optimal readability.

### 3. Table and Form Styling (30%)
- **Form UI:** Designed form fields with consistent inner padding, rounded borders, focus outline states (`:focus`), and hover effects on submit buttons.
- **Table Formatting:** Formatted the transaction history table with explicit row padding, uppercase column headers, subtle border separators, and alternating zebra-row backgrounds (`:nth-child(even)`). Added category badges for visual clarity.

### 4. Effective CSS Box Model Application (25%)
- **Separation & Spacing:** Utilized standard CSS margins to maintain vertical distance between cards, forms, and headers.
- **Inner Padding:** Standardized padding across input fields, table cells, and card sections to give interface elements appropriate breathing room.
- **Borders & Curves:** Applied subtle borders (`#e2e8f0`) and consistent `border-radius` corners across container cards, buttons, and badges.
